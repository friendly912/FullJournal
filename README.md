# FullJournal

日程管理と記録帳(数値記録・統計)を組み合わせた、完全オフライン動作のAndroidアプリです。

## 特徴

- **完全オフライン** — サーバー通信なし。すべてのデータは端末内のRoom(SQLite)に保存されます。
- **日程管理** — カレンダー表示、予定のCRUD、繰り返し予定(毎日/毎週/毎月)、ローカル通知によるリマインダー(端末再起動後も維持)。
- **記録帳(カスタム表)** — テーマ別に表を自由に作成し、列を「数値・日付・テキスト・選択肢」から自由に定義できます。よく使う構成(体重表・血圧表・支出表・運動記録表)はテンプレートから即作成可能。
- **統計・軽量AI** — 合計/平均/最大最小、週次・月次の自動集計、折れ線グラフでの推移表示、カテゴリ別クロス集計、標準偏差ベースの異常検知(通信不要でその場で計算)。
- **目標値・達成率** — 数値列に任意で目標値を設定すると、統計画面に進捗(プログレスバー)を表示。
- **検索** — 予定・表名・記録した値を横断的に検索。
- **バックアップ/復元** — データベースをファイルにエクスポート・インポート(端末変更時などに利用)。
- **ダークモード** — システム設定に追従、またはアプリ内で手動切り替え。
- **ホーム画面ウィジェット** — 今日の予定と最新の記録を表示。

## ビルド方法

Android Studioでプロジェクトルートを開き、Gradle同期後に実行してください。

コマンドラインの場合:

```bash
./gradlew assembleDebug
```

生成されたAPKは `app/build/outputs/apk/debug/app-debug.apk` に出力されます。

## ディレクトリ構成(概要)

```
app/src/main/java/com/fulljournal/app/
├── data/            Room エンティティ・DAO・データベース定義
├── ui/
│   ├── schedule/    日程管理(カレンダー・予定編集)
│   ├── records/     記録帳(表の作成・データ入力・統計)
│   ├── search/      検索
│   └── settings/    設定(テーマ・バックアップ/復元)
├── util/            リマインダー・バックアップ・日付処理などの共通処理
└── widget/          ホーム画面ウィジェット
```

## 既知の制約

- Roomのスキーマ変更に対する正式なマイグレーションは未実装です。アプリ更新でスキーマが変わった場合、`fallbackToDestructiveMigration()` によりローカルデータがリセットされます。重要なデータは設定画面の「バックアップを作成」で事前に書き出しておくことを推奨します。
- ランチャーアイコンは簡易的なベクター画像です。
